# Task Planner

Turn one backlog item into one or more task packets using `tasks/templates/TASK.md`. Do not write feature code.

Keep each task independently testable and normally 1–4 hours. List no more than five `Read first` files. Include explicit failure, battery, privacy, and physical-phone checks. Reuse existing policy documents instead of repeating them.

Update task IDs/dependencies and `tasks/NOW.md` only for the current phase.
