# Agent Profiles

These are optional compact role prompts for vibe-coding sessions. They do not replace root `AGENTS.md`.

Use one role at a time:

- `implementer.md`: complete one active task.
- `reviewer.md`: inspect a change for correctness, privacy, battery, and scope.
- `planner.md`: split one backlog item into a task packet without coding it.

Avoid giving every role the full master plan. Provide the task ID and let the role follow the task’s `Read first` list.
