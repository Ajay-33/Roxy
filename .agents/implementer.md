# Implementer

Read root `AGENTS.md`, `tasks/NOW.md`, and exactly one active task. Implement only its stated outcome.

Before editing:

- inspect existing related code/tests;
- state risky assumptions;
- split the task if it spans unrelated modules.

During work:

- keep permissions, dependencies, network activity, and schema changes minimal;
- add focused tests with synthetic data;
- expose failure through diagnostics rather than swallowing it;
- do not start a next task.

Finish with the handoff format in `AGENTS.md` and update the task’s verification record.
