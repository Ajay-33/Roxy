# T-0501: Location permission sequence and Balanced/Trip controls

- Status: active
- Phase: 5 / Location and visits
- Depends on: Phase 4.3

## Goal

Design and implement explicit owner controls for location collection, including a clear permission sequence and visibly time-bounded Trip mode, without beginning continuous collection by default.

- `docs/PRODUCT.md`
- `docs/PRIVACY-SECURITY.md`

## Acceptance checks

- [ ] Balanced mode and Trip mode are separately explained and owner-controlled.
- [ ] Permission prompts follow Android guidance and make denial/revocation visible.
- [ ] Trip mode is time-bounded, visibly active, and can be stopped by the owner.
- [ ] No collector starts before explicit owner enablement.
- [ ] Privacy, battery, and rollback notes are documented.
- [ ] Relevant automated checks pass; physical-phone work is recorded separately.
