# T-0417: Deterministic notification metadata analytics

- Status: active
- Phase: 4.2 / Owner analytics
- Depends on: T-0416

## Goal

Turn metadata-only notification events into useful, deterministic owner analytics: volume over time, app ranking, burst/quiet windows, and arrival/dismissal breakdowns.

## In scope

- Authenticated server aggregate queries over existing notification metadata only.
- Android Alerts analytics cards/visual summaries from real results.
- Deterministic synthetic tests for ranking, hourly totals, and empty/incomplete states.

## Out of scope

- Notification text, semantic inference about content, AI summaries, new collectors, or browser dashboard.

## Privacy note

- Data classes: existing metadata only—event time, event kind, package identifier, and redaction count.
- No notification text, sender, title, body, action, image, or raw payload is added.
