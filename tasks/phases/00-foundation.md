# Phase 0: Foundation

## Outcome

A fresh checkout can be understood, checked, connected to a local database, and installed as a minimal APK on the target phone.

## Includes

- owner/device/deployment decisions;
- Android project generation;
- local pgvector database;
- TypeScript package initialization;
- synthetic fixtures and root checks.

## Exit gate

- `tasks/NOW.md` Phase 0 gate passes.
- Android and server tool versions are documented.
- Secrets and personal data are absent from tracked files.
- Baseline battery measurement has scheduled dates.
