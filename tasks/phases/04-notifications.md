# Phase 4: Notifications

## Outcome

Roxy captures useful notification metadata and explicitly selected text while blocking/redacting sensitive sources on the phone.

## Exit gate

- Package policy supports blocked, metadata-only, and selected-text modes.
- Updates, groups, ongoing, removal, disconnect, and permission revocation are tested.
- Banking/authenticator/password-manager fixtures never upload text.
- Raw text retention is enforced.
- Physical-phone privacy/reliability/battery checks pass.
