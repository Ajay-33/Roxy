# Phase Gates

Phases describe outcomes and gates; `tasks/BACKLOG.md` owns task order.

| Phase | Outcome | Do not start until |
|---:|---|---|
| 0 | Reproducible foundation | owner decisions recorded |
| 1 | Lossless offline-to-server event flow | Phase 0 gate |
| 2 | Trustworthy app-usage facts | Phase 1 gate |
| 3 | Useful timeline and exact answers | Phase 2 gate |
| 4 | Safe notification collection | Phase 3 useful on its own |
| 5 | Battery-aware location and visits | notification collector stable |
| 6 | Daily review, control, backup | core collectors stable |
| 7 | Evidence-based AI memory/chat (MVP) | deterministic facts trusted |
| 8 | Explainable patterns | 2–4 weeks reliable history |
| 9 | Proactive suggestions | patterns confirmed and reviewed |

An exit gate needs recorded evidence. Elapsed calendar time or compiled code alone does not pass a gate.
