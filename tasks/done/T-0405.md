## Goal

Allow the owner to make an explicit, reversible per-package text-mode choice, apply the on-device sanitizer before persistence, and enforce seven-day local retention.

## In scope

- Add an explicit `TEXT_REDACTED` package policy that is never the default and can be changed back locally.
- Require an owner-visible warning and package-specific action before text mode can be selected.
- Route future text candidates through `NotificationSanitizer` before any local row is written; retain only redacted text and a redaction count.
- Add a local seven-day retention deletion and safe count-only result for those rows.
- Test opt-in gating, sanitizer-before-persistence, retention boundary, and policy reversal with synthetic data.

## Out of scope

- Selecting any personal package on the owner's behalf, enabling text mode during physical testing, upload/sync/API changes, AI use, or any content log/display.
