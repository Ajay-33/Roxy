# T-0302: Android Today/Timeline shell and incomplete-data state

## Goal

Add a visible Android Today/Timeline shell that lets the owner select Today or a prior local date and clearly explains that aggregate timeline coverage is incomplete until a future read integration supplies verified data.

## In scope

- Add a compose-only Today/Timeline section to the existing diagnostic screen.
- Provide deterministic local-date navigation for Today and the preceding day.
- Present safe empty and incomplete-coverage language, including an explicit statement that phone inactivity is not confirmed sleep.
- Keep a visible, payload-free placeholder while timeline fetching is not yet connected to the deployed API.
- Add focused unit tests for the date/navigation and display-state model.
