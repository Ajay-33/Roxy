## Goal

Advance a durable UsageStats collection cursor only after a successful bounded foreground collection, while intentionally overlapping reads and deduplicating observations.

## In scope

- Durable cursor and observed-usage identity store with a Room migration.
- Fixed, bounded overlap for prior-window reads.
- Deterministic observation identity and idempotent insert behavior.
- Owner-triggered foreground collection only.

## Out of scope

- Scheduling, background polling, sync, daily aggregation, labels, or raw usage display.

## Battery note

- Expected callbacks/queries per day: zero by default; owner-triggered only.
- Expected rows and upload bytes per day: local observations only; zero upload.
- Location/foreground service/wake lock impact: none.
- Required physical-phone measurement: run repeated owner-triggered collection and confirm no service or scheduled work.

## Privacy note

- Data classes touched: package identifier, aggregate foreground duration, bounded interval, and a deterministic local identity.
- Redaction/retention impact: no logs, labels, upload, or individual usage UI.
- New permission or secret: none.

## Implementation notes

The cursor advances only after all normalized observations insert idempotently. Use a small fixed overlap to tolerate delayed UsageStats updates; later aggregation owns any retained totals.
