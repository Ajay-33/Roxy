## Battery note

- Expected callbacks/queries per day: event-driven listener callbacks only; deduplication is an indexed local lookup per candidate event, with no polling.
- Expected rows and upload bytes per day: at most one local lifecycle row per distinct policy-approved notification; zero uploads.
- Location/foreground service/wake lock impact: none.
- Required physical-phone measurement: T-0406 verifies representative update/group behavior and battery attribution.

## Privacy note

- Data classes touched: a local, non-reversible identity digest derived from safe notification lifecycle identifiers; no text, extras, actions, images, tokens, or contacts.
- Redaction/retention impact: T-0404 remains required before any broader metadata or text handling. No new permission or secret.

## Implementation notes

Use only platform lifecycle identifiers required to recognize the same notification; hash them locally and never log/store the original identity. Treat group summaries as non-countable and fail closed when an identity is absent.
