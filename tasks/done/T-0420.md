# T-0420: Android notification intelligence dashboard

- Status: done
- Phase: 4.3 / Notification intelligence and dashboard experience
- Depends on: T-0419 implementation

## Goal

Present notification activity as an honest, owner-facing aggregate dashboard.

## In scope

- Day/week/month controls; summary, hourly bars, source rankings, lifecycle balance, burst windows, and explicit unavailable states.
- Local-only package-label resolution while rendering.

## Out of scope

- Notification content, message counts, new collectors, background refreshes, permissions, or remote labels.

## Acceptance checks

- [x] The UI renders deterministic aggregate-only analytics with day/week/month controls.
- [x] Labels say notification activity/updates, never messages.
- [x] Owner labels are resolved only during local rendering.
- [x] Manual paired-phone visual validation after reconnect: owner reviewed the installed dashboard; responsive stacked layout and analytics detail are visible without overlap.

## Privacy and battery note

Owner-initiated reads only; no new data classes, collectors, polling, foreground service, wake lock, or permissions.
